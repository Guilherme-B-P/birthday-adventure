# 🎂 Birthday Adventure

Joguinho de plataforma feito com carinho para um aniversário. 💜

## Rodar localmente

```bash
npm install
npm run dev
```

Abra o link informado pelo Vite no navegador. Controles: **A/D ou setas** para andar, **Espaço / seta para cima** para pular; no celular, use os botões na tela.

## Publicar

Use um serviço de hospedagem estática compatível com Vite (diretório de build: `dist`).

> Primeira versão: personagem desenhada por código, plataformas, oito presentes e tela de aniversário. Personalize personagem, nome e mensagem depois.
